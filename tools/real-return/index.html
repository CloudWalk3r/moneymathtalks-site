Real Return Calculator

Your return after inflation, using the exact (Fisher) formula.

A return of a few percent sounds like progress, but if prices rose almost as fast, your buying power barely moved. The real return is the growth left after inflation. Enter a nominal return and an inflation rate. The calculator shows the real return.

How it works

The exact formula divides 1 plus the nominal return by 1 plus inflation, then subtracts 1. A quick shortcut is to subtract inflation from the return, which gives a slightly higher figure. If inflation is higher than the return, the real return is negative: the balance grows but buys less than before.

Worked example

A nominal return of 7.00% with inflation at 3.00% gives a real return of 3.88%. The quick shortcut would say 4, so the exact formula is a little lower.

Notes

  • Compare savings rates against inflation, not against zero.
  • Use the real return for long-term plans written in today's money.
  • Fees reduce the nominal return before inflation is even counted.
  • Try a higher inflation rate to see how quickly real growth disappears.

FAQ

What is a nominal return?

The headline return before adjusting for inflation.

Why not just subtract inflation?

Subtracting is a good estimate, but the exact formula accounts for growth compounding on growth.

Can a real return be negative?

Yes, whenever inflation is higher than the nominal return.
